# CS50 Student Results System

A console-based C++ application designed to query student performance data using basic concepts such as parallel arrays, linear search, and control structures.

## Features
- **Individual Search**: Search for student records by ID (101 - 110).
- **Letter Grades**: Automatic calculation of letter grades (A, B, C, D, F).
- **Display All**: View all student records at once by entering `100`.
- **Class Average**: Calculate class average performance by entering `99`.

## Technologies Used
- **Language**: C++
- **Data Structure**: Parallel Arrays
- **Concepts**: Linear Search, Conditional Statements, While/For Loops
